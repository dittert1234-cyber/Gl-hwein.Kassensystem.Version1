# dolio vinum – Kasse v1

Erste responsive Kassen-Demo für den Glühweinstand „dolio vinum“.

## Start
`index.html` öffnen oder das Verzeichnis als GitHub Pages veröffentlichen.

## Funktionen
- Handy- und Tablet-Layout
- Produktkacheln und Kategorien
- Warenkorb + Mengenänderung
- Produktpreis + Pfand automatisch
- Pfandrückgabe, auch gleichzeitig mit Einkauf
- Barzahlung + Wechselgeld
- Kartenzahlung als Demo-Buchung
- Produktverwaltung mit änderbaren Preisen
- lokale Speicherung per localStorage
- Tagesabschluss / Auswertung

## Wichtig
V1 ist **nicht für den steuerlich relevanten Echtbetrieb** bestimmt. TSE, DSFinV-K, revisionssichere Protokollierung, Belegausgabe, Backup-/Aufbewahrungskonzept und echte Terminal-Anbindung müssen für einen produktiven Einsatz noch umgesetzt und geprüft werden.

Die Startprodukte und Preise basieren auf der bereitgestellten Preisliste. Das dort genannte Pfand von 2,50 € für Glas/Tonbecher wird als Produkteigenschaft geführt; kleine Schnäpse haben in der Vorlage kein Pfand.
